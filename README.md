# Data Analyst Portfolio

A collection of practical data analysis projects created while learning and developing my skills in **Python, pandas, JupyterLab and data analysis**.

Some projects are coursework from the **Data Analysis with Python, 10 ECTS** course at **Metropolia University of Applied Sciences Open Studies**, while others are independent practice projects.

## Projects

### Health Spending and Life Expectancy

A practical pandas and Python project analysing health spending and life expectancy across six countries between 1970 and 2020.

The project demonstrates a basic data-analysis workflow:

**Import → Inspect → Validate → Analyse → Visualise → Export → Explain**

More projects will be added to this repository as I continue developing my data analysis skills.
